(02) How it's made

File to
finished.

Scroll to run the job. Four steps between an idea and the thing on your desk.

  1. 01

    Model

    It starts as a 3D file — one of ours, or one you send over. Only have a sketch? We can model it.

  2. 02

    Slice

    The model is cut into hundreds of 0.2 mm layers, and each one becomes a path for the nozzle.

  3. 03

    Print

    Hot plastic goes down one layer at a time. Small pieces take an hour or two; big ones run overnight.

  4. 04

    Ship

    Cleaned up, checked over, packed. Then it's yours.

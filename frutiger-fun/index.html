Frutiger Fun

A free-roam stroll through a glossy, green, 2000s-future city. Walk the boardwalk, wander the hills and pop as many bubbles as you can.

Character: "Aero", built in code after the Frutiger Aero Character V2 on Sketchfab. Put an exported assets/character.glb next to the game to use that model instead.

Made with three.js and the Nunito typeface. Every texture, tree, tower and sound is generated when the game starts.
